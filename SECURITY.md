# Security policy

## Reporting a vulnerability

Open a [private vulnerability report](https://github.com/adityalenova/cyrus-ai/security/advisories/new).
Please do not file a public issue, and do not open a pull request that fixes a
security problem before it is reported privately.

Expect an acknowledgement within a week. This is a one-maintainer project, so
that is honest about the pace you get.

## What counts

- Anything that exposes another person's data, session or saved items.
- Authentication or authorization bypass, including the email and OAuth flows.
- Injection through a URL parameter, a stored value or a rendered description.
- Server-side request forgery or unbounded work triggered by a public route.

## What does not

- Rate limits and abuse of public read-only endpoints, unless they take the service down.
- Findings that require physical access to your own machine.
- Third-party services we do not operate. Report those to the provider.

## How this app actually works, so you can skip the dead ends

- Browsing needs no account. Sign-in state, saved repositories, watchlists and
  match profiles live in your browser's `localStorage`.
- The catalog is a snapshot of public GitHub and organizer data, regenerated by
  scripts. Public data in the index is not a disclosure.
- OAuth exchange and email delivery run server-side. Client secrets belong in
  environment variables, never in the bundle, and `.env` plus `.github-secret`
  are gitignored for that reason.
