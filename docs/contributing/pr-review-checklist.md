# Pull Request Review Checklist

## Code Standards
- [ ] Clean TypeScript types without `any`.
- [ ] Follows existing styling tokens (coffee/honey theme).
- [ ] No extraneous console logs or debug code.

## Testing
- [ ] Unit tests pass via `npm test`.
- [ ] Playwright E2E suites pass.

## Accessibility
- [ ] Semantic HTML and WAI-ARIA roles.
- [ ] Full keyboard navigation support.
