# Design System Tokens

## Palette
- `--color-coffee`: Primary brand dark tone (`#1C1917` / `#292524`).
- `--color-honey`: Warm gold accent (`#D97706`).
- `--color-steam`: Subtle foreground light tone for dark themes.
- `--color-card`: Elevated container surface background.
- `--color-line`: Subtle 1px structural dividing lines.
