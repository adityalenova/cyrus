# Internationalization (i18n) Roadmap

## Phases
1. **Phase 1**: Extract static text strings into JSON message dictionaries.
2. **Phase 2**: Introduce `next-intl` middleware with locale subpaths (`/en/`, `/es/`, `/hi/`).
3. **Phase 3**: Dynamic SEO hreflang tags for all localized routes.
4. **Phase 4**: Community crowdsourced translation contributions.
