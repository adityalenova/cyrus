# Open Source Programs Taxonomy

## Supported Categories
- **Mentored Programs**: GSoC, LFX Mentorship, Outreachy, Summer of Bitcoin.
- **Hackathons**: MLH, Hacktoberfest, Global Hack Week.
- **Fellowships**: Major League Hacking Fellowship, Linux Foundation Fellowships.

## Criteria for Inclusion
Must have a verified public program page, distinct project guidelines, and clear mentor or stipend structures.
