# WCAG 2.1 AA Accessibility Testing Protocol

## Audit Checklist
1. **Color Contrast**: 4.5:1 minimum for regular text, 3:1 for large text.
2. **Keyboard Navigation**: All interactive controls reachable via Tab.
3. **Screen Readers**: Test with VoiceOver (macOS) and NVDA (Windows).
4. **Motion Preference**: Honor `prefers-reduced-motion` in CSS transitions.
