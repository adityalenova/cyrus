# Core Web Vitals Performance Budgets

## Target Metrics
- **LCP (Largest Contentful Paint)**: < 2.0s
- **INP (Interaction to Next Paint)**: < 150ms
- **CLS (Cumulative Layout Shift)**: < 0.05
- **Total JavaScript Bundle**: < 160KB initial gzipped

## Optimization Rules
- Use `next/font` for self-hosted font loading.
- Lazy-load below-the-fold images.
