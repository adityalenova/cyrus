# Add unified notification center with priority levels and read state management

Implements a centralized notification system with priority levels (info, warning, urgent), read/unread state, batch operations (mark all read, dismiss), category filtering, and configurable notification preferences.

## Architecture
- `model.ts` — Pure logic, no React, no side effects
- `model.test.ts` — Unit tests (vitest)
- `README.md` — This file
