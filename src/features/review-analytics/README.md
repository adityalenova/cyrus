# Add code review analytics dashboard with turnaround time metrics

Tracks and visualizes code review performance metrics: average review turnaround time, review depth (comments per PR), approval rate, revision cycles, and reviewer workload distribution across team members.

## Architecture
- `model.ts` — Pure logic, no React, no side effects
- `model.test.ts` — Unit tests (vitest)
- `README.md` — This file
