# Add interactive project roadmap viewer with milestone tracking

Displays project milestones on a timeline with progress indicators, dependency links between milestones, status coloring (planned/in-progress/completed/blocked), and quarter-based grouping for multi-month planning.

## Architecture
- `model.ts` — Pure logic, no React, no side effects
- `model.test.ts` — Unit tests (vitest)
- `README.md` — This file
