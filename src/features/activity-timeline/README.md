# Add detailed activity timeline with event categorization and filtering

Records and displays a chronological timeline of all user activities (commits, PRs, reviews, issues, badges, streaks) with event categorization, date grouping, search filtering, and pagination support.

## Architecture
- `model.ts` — Pure logic, no React, no side effects
- `model.test.ts` — Unit tests (vitest)
- `README.md` — This file
