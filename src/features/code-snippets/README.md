# Add shareable code snippet library with syntax highlighting metadata

Provides a curated library of code snippets for common open-source contribution patterns (fork workflow, PR template, issue template, CI config) with language tagging, search, and copy-to-clipboard support.

## Architecture
- `model.ts` — Pure logic, no React, no side effects
- `model.test.ts` — Unit tests (vitest)
- `README.md` — This file
