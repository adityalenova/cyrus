# Add personal contribution goal tracker with progress milestones

Enables users to set weekly and monthly contribution goals (PRs merged, issues closed, reviews given) with progress tracking, milestone celebrations, and streak integration for consistent achievement momentum.

- `model.ts` — Pure logic, no React, no side effects
- `model.test.ts` — Unit tests (vitest)
