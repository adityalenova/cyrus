# Add FAQ management system with search, categories, and voting

Implements a structured FAQ system with hierarchical categories (Getting Started, Contributing, Programs, Technical), full-text search, helpful/not-helpful voting, and expandable accordion display model.

## Architecture
- `model.ts` — Pure logic, no React, no side effects
- `model.test.ts` — Unit tests (vitest)
